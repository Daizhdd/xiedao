# 开始使用写道

## 下载安装

从本仓库 Releases 获取 Windows x64 ZIP，解压后运行 `写道.exe`。放在可写目录，不建议放入需要管理员权限的系统目录。

Mac 用户选择对应 Apple 芯片或 Intel 的测试包，将 `写道.app` 拖入“应用程序”，详见 [Mac 使用说明](MACOS.md)。

首次启动自动建立空数据库，下载包不预置作品或模型账户。若已有写道数据，先关闭旧程序并备份旧文件夹；不要删除 `data/`。

## 配置模型

打开界面中的模型配置入口，新建配置，填写服务商、API 地址、API Key、模型名，并设置默认模型。兼容服务请选择 OpenAI 兼容类型；API 地址与模型名以你使用的服务商说明为准。

可以配置备用模型。默认模型发生空输出、超时或服务错误时，软件会按流程尝试可用备用配置；备用服务也可能产生费用。额度或余额不足需要在服务商处处理。

本地 Ollama 通过其本机兼容接口连接，模型需要事先安装和启动。写道不会附送云端 API 额度。

## 写作流程

1. 在书架新建作品，填写书名和基本构想。
2. 在写作书房沟通规划，检查生成的全书、分卷和章节大纲。
3. 启动写作任务，观察进度及当前步骤。较长任务建议先少量验证。
4. 在章节编辑器复核并修改正文，查看版本与重写候选。
5. 结合原文证据检查审稿意见，维护设定、伏笔和文风。
6. 任务停止或失败后，查看任务记录和恢复入口，再决定如何继续。

## 备份与更新

Windows 的作品、模型配置和相关写作记录在程序旁的 `data/` 中；Mac 保存在 `~/Library/Application Support/写道/`。备份时先关闭写道，再复制整个对应数据目录到安全位置。备份含 API Key，请勿公开上传。

更新：关闭程序 → 备份 `data/` → 将新版程序放入原文件夹 → 保留 `data/` → 启动并检查作品。首次运行新版前保留旧程序与数据副本，以便回退。

Mac 更新时关闭程序、备份数据目录，再替换“应用程序”中的 `写道.app`；无需将小说放进 `.app`。

手动恢复书目备份时，可以从源码环境使用 `rescue_restore.py`。先在数据副本上操作，并用 `--db` 指定副本数据库路径；恢复后人工核对正文和版本。

## 排查问题

- 无法保存：确认程序文件夹可写，磁盘空间足够。
- 模型报错：核对 API 地址、模型名、密钥、余额及服务可用性。
- 任务中断：查看任务记录，不要连续反复启动同一任务。
- 需要反馈：提交版本号和脱敏复现步骤，使用虚构短文本。
